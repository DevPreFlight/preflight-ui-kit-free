# DevPreFlight Flat UI Kit (Free Community Edition)

This is the Free Community Edition (MIT License) of the DevPreFlight UI Kit.

## Available Modules (15 Free Components):
- **13 UI Primitives**: Button, IconButton, LoadingButton, TextInput, PasswordInput, Textarea, SelectDropdown, ToggleSwitch, Checkbox, RadioGroup, Tooltip, Avatar, AvatarGroup, Chip (`packages/react/src/primitives/`)
- **2 Dashboard & Telemetry**: QuickStatsBar, StatusBadge (`packages/react/src/dashboard/`)

## Commands:
- `npm run dev` - Start development server
- `npm run build` - Build Next.js application
- `npm run type-check` - Check TypeScript types (`tsc --noEmit`)

Refer to `SKILL.md` for complete component APIs, props, and design tokens.
